# Telegram-бот с меню и приёмом заявок

Бот для малого бизнеса или фрилансера: показывает меню с услугами и принимает заявки от клиентов. Заявки сохраняются в базу данных, а администратор получает уведомление в Telegram.

## Возможности

- Главное меню с inline-кнопками (услуги, цены, контакты, примеры работ)
- Форма заявки: бот спрашивает имя и описание задачи
- Хранение пользователей и заявок в SQLite
- Уведомление администратору о каждой новой заявке
- Команда `/requests` для администратора: последние 10 заявок
- Команда `/cancel` для отмены заполнения формы


## Технологии

- Python 3.13
- aiogram 3 (асинхронная библиотека для Telegram Bot API)
- SQLite
- python-dotenv

## Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/MalykhArtyom/mytgbot.git
   cd mytgbot
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` по образцу `.env.example` и заполните его:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_ID=ваш_числовой_id_в_Telegram
   PROXY_URL=
   ```
   - `BOT_TOKEN` выдаёт @BotFather при создании бота.
   - `ADMIN_ID` можно узнать у бота @userinfobot.
   - `PROXY_URL` нужен только если Telegram недоступен напрямую (например, `http://host:port`), иначе оставьте пустым.
4. Запустите бота:
   ```
   python bot.py
   ```

## Структура проекта

```
bot.py            # логика бота: меню, форма заявки, команды
db.py             # работа с базой данных SQLite
requirements.txt  # зависимости

```
